# AI POC Report Example

## 执行摘要

说明 POC 验证了什么，以及明确没有验证什么。

## Business Problem

说明业务问题、当前流程和客户为什么值得投入。

## POC Scope

说明数据范围、样本数量、Golden Set、验收口径。

## Architecture

说明 `input -> AI -> decision -> human/business action`。

## Evaluation Metrics

只记录来自 eval runner、golden set、report 的真实 evidence。

## Verified

- 已验证能力 1
- 已验证能力 2

## Limitations

- 未验证项 1
- 未验证项 2

## Production Recommendation

说明是否进入 pilot / integration，以及下一阶段 gate。
