03 / SOLUTION ARCHITECTURE

业务系统负责权限与数据，AI 服务负责编排与检索

业务权限不旁路Python 不直接读取 Java 业务库。

两类上下文分离学生数据走 Java API，课程知识走 RAG。

AI 服务独立演进能力升级不侵入核心业务事务。
