04 / ENGINEERING RETROSPECTIVE

把失败变成可复用的工程护栏

阶段闭环：Smoke → Golden Set → 失败分析 → 展示证据。

01

Normalizer

统一完整 Artifact 与 reusable wrapper，格式不合法时在入口安全失败。

02

evidenceRefs 契约

只接受原生数组或合法 JSON 数组字符串；null、Markdown、未登记 ID 明确拒绝。

03

真实回归

每条调用记录 Run ID、状态、断言和错误摘要；关键分支额外重复验证一致性。
