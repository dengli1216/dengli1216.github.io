# Page Brief — [案例名称]

## 三层阅读目标

| 读者 | 时长 | 必须获得的结论 |
| --- | --- | --- |
| HR | 60 秒 | 业务风险、个人贡献、案例边界与可验证成果 |
| 售前 | 3 分钟 | 决策链、工作流设计、规则/Gate 取舍与客户试点路径 |
| 技术面试官 | 10 分钟 | 输入输出合同、LLM/规则分工、评测方法、故障与生产化计划 |

## 固定模块

1. 业务风险与个人贡献。
2. 决策实例：输入、结构化结论、引用、人工复核点。
3. 工作流设计图：业务架构图 + 标注后的 Dify 工作流工程图。
4. 规则/Gate 取舍：为何由规则或人工承担，不由 LLM 最终授权。
5. 测试证据：只读取 `page-evidence.json` 的已验证字段。
6. 边界与生产化计划：数据、评测、权限、监控和人工复核。

## 禁止表述

- 伪造 ROI、生产准确率、客户效果或 Live Run。
- 将 synthetic/待人工复核数据描述为生产数据或专家标注。
- 将 LLM 输出描述为不可逆或高风险决策的最终授权。
