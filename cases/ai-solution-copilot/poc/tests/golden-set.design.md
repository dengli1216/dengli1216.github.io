# Golden Set Design — AI Solution Copilot

只定义维度与断言，不生成最终样本、标签、运行指标。样本须脱敏、人工确认并版本化。

| 类别 | 预期断言字段 | 业务意义 |
| --- | --- | --- |
| Happy Path | 阶段结构、Lineage、证据引用；Assurance `PASS`；报告待人工复核。 | 验证受控主链只能交给人工。 |
| 信息缺失 | Normalizer/Gate 安全失败，或 `BLOCKED` 及非空问题清单。 | 防止资料不全时进入后续分析。 |
| 冲突/异常 | 证据/阶段校验失败，或 Assurance 非 `PASS` 且不生成报告。 | 验证治理不吞掉冲突。 |
| 边界输入 | 包装格式、最小有效 Artifact、语言枚举与格式错误处理。 | 明确两项输入的接口边界。 |
| 人工复核 | `approved_*` 或 `rejected_*`、意见和风险字段。 | 保证最终授权可留痕。 |

最终每例另定义 `case_id`、输入版本、前置条件、预期终端、结构断言、人工审阅点、敏感信息处理与是否重复运行。不得用自由文本好坏代替 Gate 断言。
