# 阶段3求职作品集页面变更

## 页面定位

AI 解决方案架构求职案例。重点展示业务建模、架构取舍、确定性风险控制和 POC 验收能力，不作为产品宣传或生产能力声明。

## 修改项

- 页面由七段收敛为六段，删除重复 Scorecard、重复边界和重复工作流说明。
- 首屏采用“案例结论 + 我的角色 + G10 决策证据卡”双栏布局。
- 新增 G10 / G30 决策瞬间，展示输入摘要、证据判断、Gate 路径和人工行动。
- 核心架构改为 LLM 归纳 → Code Gate 决策 → 人工复核；Dify 截图降为可展开辅助证据。
- 验证证据仅保留 30/30、关键 Gate 5/5 三次一致和 P95 58.257s。
- 新增个人贡献与可复用方法论、生产化下一步。

## 事实与数据来源

- 页面运行事实仅来自 `poc/reports/page-evidence.json`，说明边界来自 `poc/reports/POC_REPORT.md`。
- 数据集为 `Synthetic POC / human_review_pending`；不代表生产验收、客户效果、真实 ROI 或生产准确率。
- LLM 仅归纳条款与证据；Code Gate 计算建议；人工负责最终复核和审批。

- 原生 HTML / CSS / JavaScript，无构建步骤。

- 本地 HTTP 浏览器检查覆盖 320、768、1024、1440px：证据包加载成功、6 个主区块完整、无页面横向溢出、控制台 0 错误/0 警告；工作流辅助图可展开并完成加载。
