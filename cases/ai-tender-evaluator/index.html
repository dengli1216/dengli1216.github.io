关键架构决策
决策为什么落地机制
LLM 不决定 Bid生成结果存在概率性，不能承担资格与投标授权责任。LLM 仅抽取条款、证据与状态。
设置 Code Gate关键缺口、过期、否定表达必须得到稳定处理。规则计算 No-Bid / Conditional Bid / Bid。
校验 Schema 与引文结构错误或无原文证据时，正常结论不可被信任。解析失败安全降级；无证据不得判定 Met。
保留人工复核资质、日期、金额、法律和报价属于高责任事项。建立复核队列，人工完成最终审批。
